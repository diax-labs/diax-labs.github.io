Frequently Asked Questions

How is DiaX different from React Flow?

React Flow is a full-featured interactive graph editor with drag-and-drop, zoom, and pan. DiaX is a DOM-native visual explanation runtime: Diagram can place data-driven nodes, while Connect draws relations over JSX and CSS layouts you already own.

Is DiaX compatible with Mermaid syntax?

DiaX imports a documented Mermaid subset covering flowchart, class, state, ER, requirement, and mindmap families. Unsupported families such as Sequence and Gantt should remain on Mermaid or use a domain-specific renderer.

Does DiaX work with SSR frameworks like Next.js?

Yes. Core topology computation is server-safe. Diagram and Connect measure real DOM and render their edge overlay in the browser, so framework adapters hydrate that layer on the client.

Can I use DiaX for commercial projects?

Absolutely. DiaX is MIT licensed — free for personal and commercial use with no restrictions.

Which frameworks does DiaX support?

DiaX has official bindings for React, Vue, Svelte, Solid, and Vanilla JS. The core engine is framework-agnostic.
