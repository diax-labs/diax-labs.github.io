# SmartMermaidDiagram (/docs/ui-react/smart-mermaid)





Overview [#overview]

`SmartMermaidDiagram` parses any supported Mermaid syntax, auto-detects the diagram
type, and renders it using the matching preset node components from `@diax/ui-react`.

Supported types: `flowchart`, `classDiagram`, `stateDiagram`, `erDiagram`, `requirement`, `mindmap`.

Custom nodeTypes Override [#custom-nodetypes-override]

You can override or extend the auto-detected nodeTypes registry:

```tsx
import { SmartMermaidDiagram } from '@diax/ui-react/mermaid';

<SmartMermaidDiagram
  chart={`graph TD
    A[Custom] --> B[Nodes]
  `}
  nodeTypes={{
    default: (node) => (
      <div className="custom-node">{node.content}</div>
    ),
  }}
/>
```

Props [#props]

| Prop         | Type                                     | Default          | Description                                                           |
| ------------ | ---------------------------------------- | ---------------- | --------------------------------------------------------------------- |
| `chart`      | `string`                                 | —                | Mermaid syntax string (required)                                      |
| `nodeTypes`  | `Record<string, NodeRenderer>`           | —                | Override/extend auto-detected renderers                               |
| `renderNode` | `(node, context) => ReactNode`           | —                | Locally override nodes while retaining `context.defaultNode`          |
| `direction`  | `Direction`                              | `'horizontal'`   | Layout direction                                                      |
| `density`    | `Density`                                | `'comfortable'`  | Spacing between nodes                                                 |
| `theme`      | `ThemeName \| DiaxTheme`                 | —                | Theme preset or custom theme object                                   |
| `pathType`   | `'bezier' \| 'straight' \| 'orthogonal'` | `'bezier'`       | Edge path style                                                       |
| `className`  | `string`                                 | —                | Container class                                                       |
| `centered`   | `boolean`                                | `false`          | Center nodes in grid cells                                            |
| `fallback`   | `ReactNode \| (error) => ReactNode`      | accessible error | Custom invalid-input UI; the diagnostic is available as `error.cause` |
| `onError`    | `(error) => void`                        | —                | Observe detection or parsing failures                                 |

How It Works [#how-it-works]

1. `parseMermaid(chart)` detects and parses through one public entry
2. The matching transformer converts the supported Mermaid subset → `DiaxAST`
3. `BUILTIN_NODE_TYPES[type]` provides the default nodeTypes registry
4. Custom `nodeTypes` prop is merged on top (overrides win)
5. `FlowDiagram` renders with the resolved `nodeTypes` + `renderNode`

This is the same **component registry** pattern used by Formily — type strings
map to render functions, and the registry is extensible at runtime.
