# EntityNode (/docs/ui-react/er-diagram)





Overview [#overview]

`EntityNode` renders ER diagram entities in a table-style layout with header and attribute rows.
PK/FK/UK constraint badges include visible abbreviations, accessible names and self-contained
package styling. They do not depend on Tailwind color utilities or a host `.dark` selector.

Constraint Badges [#constraint-badges]

| Constraint | Color  | Meaning     |
| ---------- | ------ | ----------- |
| `PK`       | Amber  | Primary Key |
| `FK`       | Blue   | Foreign Key |
| `UK`       | Purple | Unique Key  |

Known abbreviations expose `Primary key`, `Foreign key` and `Unique key` to assistive technology.
Custom constraint strings remain visible and receive the neutral token. The badges also use
`data-diax-ui-part="constraint"` and `data-constraint`, so application themes can restyle them
without replacing the component structure.

For a complete parent/child schema, lifecycle and migration example, see
[Data Model Recipes](/docs/ui-react/data-model-recipes).

Props [#props]

EntityAttribute [#entityattribute]

| Prop         | Type                             | Description      |
| ------------ | -------------------------------- | ---------------- |
| `name`       | `string`                         | Attribute name   |
| `type`       | `string`                         | Data type        |
| `constraint` | `"PK" \| "FK" \| "UK" \| string` | Constraint badge |
