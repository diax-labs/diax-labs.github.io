# ClassNode (/docs/ui-react/class-diagram)





Overview [#overview]

`ClassNode` renders UML class diagram nodes with three sections: header (name + stereotype),
attributes, and methods. Supports both compound composition and data-driven modes.

Visibility Indicators [#visibility-indicators]

UML visibility symbols are color-coded:

| Symbol | Visibility | Color |
| ------ | ---------- | ----- |
| `+`    | public     | Green |
| `-`    | private    | Red   |
| `#`    | protected  | Amber |
| `~`    | package    | Blue  |

Props [#props]

ClassNode [#classnode]

| Prop          | Type                                           | Description      |
| ------------- | ---------------------------------------------- | ---------------- |
| `data`        | `{ name, stereotype?, attributes?, methods? }` | Data-driven mode |
| `highlighted` | `boolean`                                      | Accent ring      |
| `dimmed`      | `boolean`                                      | Reduced opacity  |

ClassHeader [#classheader]

| Prop         | Type     | Description                                    |
| ------------ | -------- | ---------------------------------------------- |
| `stereotype` | `string` | UML stereotype (e.g., "interface", "abstract") |

ClassAttributes / ClassMethods [#classattributes--classmethods]

| Prop    | Type       | Description                                          |
| ------- | ---------- | ---------------------------------------------------- |
| `items` | `string[]` | Member strings (prefix with +/-/#/\~ for visibility) |
