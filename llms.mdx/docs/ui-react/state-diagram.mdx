# StateNode (/docs/ui-react/state-diagram)





Overview [#overview]

`StateNode` renders state machine nodes with three variants: default (rounded rectangle),
initial (filled circle), and final (double circle).

Props [#props]

| Prop          | Type                                | Default     | Description        |
| ------------- | ----------------------------------- | ----------- | ------------------ |
| `variant`     | `"default" \| "initial" \| "final"` | `"default"` | Node shape variant |
| `active`      | `boolean`                           | `false`     | Accent border glow |
| `highlighted` | `boolean`                           | `false`     | Ring + scale       |
| `dimmed`      | `boolean`                           | `false`     | Reduced opacity    |
