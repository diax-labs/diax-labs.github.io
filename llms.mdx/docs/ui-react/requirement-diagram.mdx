# RequirementNode (/docs/ui-react/requirement-diagram)





Overview [#overview]

`RequirementNode` renders requirement diagram nodes with type classification badges,
priority indicators, and optional risk levels.

Type Badges [#type-badges]

| Type          | Color  |
| ------------- | ------ |
| `functional`  | Blue   |
| `performance` | Orange |
| `interface`   | Violet |
| `design`      | Teal   |
| `physical`    | Rose   |

Priority Indicators [#priority-indicators]

| Priority | Indicator |
| -------- | --------- |
| `high`   | Red dot   |
| `medium` | Amber dot |
| `low`    | Green dot |

Props [#props]

RequirementNode [#requirementnode]

| Prop       | Type                          | Description            |
| ---------- | ----------------------------- | ---------------------- |
| `type`     | `RequirementType`             | Category badge         |
| `priority` | `"high" \| "medium" \| "low"` | Priority dot           |
| `risk`     | `"high" \| "medium" \| "low"` | Risk footer            |
| `reqId`    | `string`                      | ID displayed in header |

ElementNode [#elementnode-1]

| Prop          | Type     | Description                                   |
| ------------- | -------- | --------------------------------------------- |
| `elementType` | `string` | Type annotation (e.g., "module", "component") |
