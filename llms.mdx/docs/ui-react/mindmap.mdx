# MindmapNode (/docs/ui-react/mindmap)





Overview [#overview]

`MindmapNode` renders depth-aware mindmap nodes. Colors cycle through a built-in
palette based on `depth`, and font/padding sizes decrease at deeper levels.

Color Cycling [#color-cycling]

The depth palette cycles through 6 colors: violet → amber → emerald → sky → rose → orange.
After depth 5 the cycle repeats.

Sizing [#sizing]

| Depth | Font                      | Padding       | Border Radius |
| ----- | ------------------------- | ------------- | ------------- |
| 0     | `text-lg font-bold`       | `px-5 py-3`   | `rounded-xl`  |
| 1     | `text-base font-semibold` | `px-4 py-2`   | `rounded-lg`  |
| 2+    | `text-sm`                 | `px-3 py-1.5` | `rounded-md`  |

Props [#props]

| Prop       | Type        | Default | Description                            |
| ---------- | ----------- | ------- | -------------------------------------- |
| `depth`    | `number`    | `0`     | Nesting depth, controls color + sizing |
| `children` | `ReactNode` | —       | Node label content                     |
