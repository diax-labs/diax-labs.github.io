Question-First Recipe

Which real interface crosses each application boundary, and who owns it?

Use Connect because authored DOM and CSS own the layers; let DiaX measure stable targets and route only the declared relations.

Use this shape when

  • Connect an existing responsive JSX or Tailwind system layout without surrendering its composition
  • Explain browser, edge, service, worker, and storage responsibilities in a product architecture

Choose another shape when

Avoid Connect when the topology itself should decide placement or when the content must remain framework-neutral JSON.

  1. The architectural layers and their owners
  2. The direction of requests, events, and stored data
  3. The protocol or contract on every meaningful relation
  4. The responsive reading order without the edge overlay
