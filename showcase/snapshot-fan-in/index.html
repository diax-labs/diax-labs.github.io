Question-First Recipe

How do independent quality inputs become one trusted read model?

Use Connect because the staged report, projection and output DOM owns the composition. Label durable writes and asynchronous events in text and retain stable relation IDs across refreshes.

Use this shape when

  • Explain several independently written reports converging into one queryable snapshot
  • Show how a stable read model fans out to dashboards, statistics and asynchronous delivery

Choose another shape when

Avoid this dense authored surface when the topology is small enough for automatic Diagram layout or when no persistent read model exists.

  1. The downstream reads and asynchronous events
  2. The exact durable snapshot fields
  3. The identity used to join project and branch data
  4. The independent source payloads and their write owners
