Question-First Recipe

Which source facts justify this architecture decision at one exact repository revision?

Verify Git facts in an authoring or build step, then pass trusted links into EvidenceNode and use Connect only for the declared review relationship.

Use this shape when

  • Explain an architecture decision with reviewable file and line evidence
  • Give an AI-generated technical map citations that survive branch movement

Choose another shape when

Avoid this recipe when the repository is private to the audience, the revision or line ranges cannot be verified, or the visual would imply runtime causality that the source does not establish.

Facts the author or agent must know first

  1. A full 40-character commit SHA
  2. A public HTTPS repository URL
  3. Repository-relative POSIX file paths
  4. The bounded decision each fact supports without inventing causality
  5. Verified line ranges at that exact commit
Copy-ready agent prompts

English

Create a source-grounded DiaX Connect study from a public repository. Pin a full commit SHA, verify every file and line range at that revision, render citations as trusted DOM links, and connect facts only to the decision they explicitly support. Fail closed on missing evidence.
