Question-First Recipe

Which independent controls make an AI answer grounded, authorized and reviewable?

Use Diagram because topology and nested containment own placement; render system, durable-store and evidence roles as ordinary DOM and keep geometry automatic. Preserve readable node, edge-label and group-title type on narrow screens: use a visibly labelled horizontal reading canvas instead of scaling the complete architecture down.

Use this shape when

  • Explain how an online retrieval path consumes a separately versioned knowledge index
  • Review cache, authorization, retrieval, ranking and citation responsibilities as one system

Choose another shape when

Avoid this architecture when the product performs no retrieval, or when a short sequence can explain the behavior without system boundaries.

Facts the author or agent must know first

  1. The authorization and tenant boundary applied before retrieval
  2. The cache key and invalidation policy
  3. The citation identity retained with every material answer claim
  4. The retrieval and reranking responsibilities
  5. The source revision and access metadata stored with every chunk

English
