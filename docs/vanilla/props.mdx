`CreateDiagramOptions<NodeContent, EdgeLabel, GroupLabel>` keeps node content, edge-label data, and
group-label data independent. String DSL labels remain strings, so `renderEdgeLabel` receives
`EdgeLabel | string`. Inference is preferred; the explicit order exists for empty definitions and
reusable renderer callbacks.
