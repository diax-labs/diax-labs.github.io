# FlowNode (/docs/ui-react/flowchart)





Overview [#overview]

`FlowNode` renders flow diagram nodes with configurable shapes via the `variant` prop.

Variants [#variants]

| Variant    | Shape                  | Use Case          |
| ---------- | ---------------------- | ----------------- |
| `default`  | Rounded rectangle      | General steps     |
| `decision` | Diamond (rotated)      | Yes/No branches   |
| `terminal` | Stadium/pill           | Start/End         |
| `database` | Cylinder top           | Databases, stores |
| `process`  | Sharp rectangle        | Processing steps  |
| `io`       | Parallelogram (skewed) | Input/Output      |

Props [#props]

| Prop          | Type          | Default     | Description                 |
| ------------- | ------------- | ----------- | --------------------------- |
| `variant`     | `FlowVariant` | `"default"` | Shape variant               |
| `highlighted` | `boolean`     | `false`     | Accent ring + scale         |
| `dimmed`      | `boolean`     | `false`     | Reduced opacity             |
| `className`   | `string`      | —           | Additional Tailwind classes |
