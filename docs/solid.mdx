Progressive API [#progressive-api]

DiaX provides three levels of control. Choose based on your needs:

| Layer | API                              | Best for                               |
| ----- | -------------------------------- | -------------------------------------- |
| 1     | `<FlowDiagram>` / `<Mindmap>`    | Quick usage, AI output, prototyping    |
| 2     | `<FlowDiagram renderNode={...}>` | Custom styling with your design system |
| 3     | `useDiagram()` hook              | Full headless control, library authors |

***

Quick Start [#quick-start]

The simplest way to use DiaX — just pass nodes and relations:

```tsx contract solid
import { FlowDiagram } from '@diax/solid';

function MyDiagram() {
  return (
    <FlowDiagram
      nodes={[
        { id: 'client', content: 'Browser' },
        { id: 'api', content: 'API Server' },
        { id: 'db', content: 'Database' },
      ]}
      relations={[
        'client->|HTTPS|api',
        'api->|SQL|db',
      ]}
      density="comfortable"
    />
  );
}
```

Density [#density]

Control spacing with the `density` prop:

| Value           | Description                             |
| --------------- | --------------------------------------- |
| `"compact"`     | Tight spacing, good for inline diagrams |
| `"comfortable"` | Default, balanced spacing               |
| `"spacious"`    | Wide spacing, good for presentations    |

Direction [#direction]

```tsx
<FlowDiagram direction="horizontal" />         // Left to right (default)
<FlowDiagram direction="vertical" />            // Top to bottom
<FlowDiagram direction="horizontal-reverse" />  // Right to left
<FlowDiagram direction="vertical-reverse" />    // Bottom to top
```

| Value                  | Description                    |
| ---------------------- | ------------------------------ |
| `"horizontal"`         | Left to right (default)        |
| `"vertical"`           | Top to bottom                  |
| `"horizontal-reverse"` | Right to left (RTL flows)      |
| `"vertical-reverse"`   | Bottom to top (upstream flows) |

Layout Algorithms [#layout-algorithms]

Use the dedicated component for each layout type:

```tsx
import { FlowDiagram, Mindmap } from '@diax/solid';

<FlowDiagram nodes={...} relations={...} />  // DAG layout
<Mindmap nodes={...} relations={...} />       // Center-outward radial
```
